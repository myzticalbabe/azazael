## META-LEVELS-CANON-v1 — meta-reflect vs meta-cog, sweet-spot, scope, Heaven (canonical, all lanes; mirrors /root/BCC-REINVESTIGATION/AGENTS.md §7; full text: /root/BCC-REINVESTIGATION/02_analysis/findings/META_LEVELS_CANON_2026-10-27.md; user-decreed 2026-10-27)

- Two paradigms: META-REFLECT = offline RL over trial trajectories (success AND failure), validated, append-only, retrieved later — product is semantic memory, learns BETWEEN episodes. META-COG = online monitoring-to-control, episodic critique in working memory — product is control, learns WITHIN the episode, acts now.
- Ladder: L0 INSTANCE (trajectory, no generality claimed) / L1 SWEET SPOT (exactly once removed: falsifiable, evidence-linked min 3 trajectories, non-duplicate, bounded — would change a CLASS of decisions) / L2 SCOPE (only legitimate second step: applicability boundary, still validation-grade) / L3+ HEAVEN EXCLUDED ("always verify ownership" — true everywhere, decides nowhere; fails materiality, scope, evidence-link).
- Stop rule: climb instance -> rule -> applicability, then STOP. One level between sweet-spot and Heaven; Heaven never stored. Mechanical enforcement: ledger cap 200, prune by retrieval count never age — Heaven-rules match everything, discriminate nothing, are retrieved never, die of disuse.
- Heaven tests: CLASS test (name the decision-class + three trajectories or drop it) and DIARY test (senseless without its incident = L0 diary; sensible in EVERY incident = Heaven). Heaven-factories: N=1 over-generalization, unnamed-mechanism downgrade, eloquence-as-truth. Acceptance language ("this is correct/done") is forbidden — only the user accepts.
- Relation: FLOOR L0-L4 is the evidence ladder for THREADS; META L0-L2/H is the abstraction ladder for LESSONS. Neither accepts eloquence as payment.
