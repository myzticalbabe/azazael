# THE UNIFIED COURT EVIDENTIARY ADMISSIBILITY STANDARD

**Version:** CAAS-1.0
**Date:** 2026-11-05
**Authority:** standing order for every lane, every claim, every negative.
**Supersedes nothing by deletion.** The tier vocabulary in `flock-canon`, the claim
rule in `HYPER-EDGE-DEFAULTS HED-7`, and the verification ladder in `RULE 0T` are
absorbed here as Parts I–III. Where an older document states a rule this file does
not, that rule still stands; where it contradicts this file, this file wins and the
contradiction is a defect to record.

---

## 0. The one sentence

**A statement is admissible when it names the command that produced it, the digest
that command printed, the tier of the source behind it, and the universe it is a
negative about — and when the instrument that read it can be shown to discriminate.**

Everything below is that sentence, spelled out so it can be checked by someone who
was not in the room.

---

## PART I — ADMISSIBILITY OF A FINDING

### A1. A claim carries its command

`done`, `fixed`, `passes`, `verified`, `landed`, `in place`, `cleared`, `clean`,
`complete` are **claims**. Each is written with the command and the line it printed.

- Admissible: `golden_arrow --staged: 6 files, 0 new defects`
- Admissible: `defaults_profile --check -> OK: defaults profile valid ... EXIT=0`
- **Not** admissible: "the knobs are wired", "the suite is green", "tests pass".
- **Not** admissible: a number with no command, even a number that is correct.
  A correct number without provenance cannot be distinguished from a lucky guess,
  and the difference is exactly what a court is for.

*Bought by:* HED-1 — months of import sweeps missed a live `NameError` because
"imports clean" was reported as "works".

### A2. Provenance is the tool invocation, not the memory of one

Every harvest row and every acceptance proof cites **the invocation**: command,
outcome, digest. Recalled numbers, committed reports read after the fact, `/tmp`
copies run outside project import context, and single-invocation counts are
**forbidden evidence**.

Two readings that disagree (whole-tree vs per-file) reconcile by **re-running**,
never by picking the preferred one.

*Bought by:* 2026-11-02 — a one-file `golden_arrow --file` run overwrote
`logs/golden_arrow.json`, leaving a 1-file artifact answering for a 499-file tree.

### A3. Tier decides what a document can prove

| tier | source | can it establish |
| --- | --- | --- |
| **A** | primary document (filing, contract, docket, raw capture + sha) | a **fact**, VERIFIED-eligible |
| **B** | official index (registry, licence list, NPI, EIN record) | **identity / universe** only |
| **C** | credible secondary (reporting, minutes, deal page) | corroboration **paired with A or B**, else LEAD |
| **D** | snippet, social, hearsay, AI summary, archived pointer | **LEAD only**, logged, never proof |

A tier-B index may prove *that an entity exists and how it is identified*. It may
not prove what the entity did. A tier-C page may not carry a fact alone. A tier-D
item is a queue entry, not a finding.

*Bought by:* the flock-canon proof rules, where a name-only hit was repeatedly read
as a confirmed relationship.

### A4. Identity needs two keys (persons) or one object key (orgs)

A person is identified by **two independent keys** (name + DOB, name + licence,
name + address+date). An organisation by EIN or registry objectID. **Name-only is
LEAD**, always, and must be labelled as such.

### A5. A quote must be found in its source

Every exhibited quotation passes a **grounding check**: the quoted text occurs in
the cited capture. An ungrounded quote is not weak evidence, it is **no evidence**,
and citing it is a falsification whether or not it was generated by a model.

*Measured 2026-11-05:* all 42 arena rows carry `quote_is_grounded: true` against
`ARC/cain/evidence_packet.json` — the check is live and its negative case is
exercised elsewhere; a pin with no quotable line returns
`quote_is_grounded: false` and is counted in `ungrounded_quotes`.

### A6. A reading carries its denominator

Any verdict that summarises a population states **N of M**. `PASS` with no count is
inadmissible as a population claim — it is at most a claim about one run.

*Measured 2026-11-05:* `tools/reading_audit.py` reports
`coverage: 33/66 artifact(s) carry a usable denominator (50%; floor 0%)`.
The remaining 33 artifacts are named with `denominator_free`, including
`hook_evidence.json`, `one_click.json` and `pin_audit.json`. A floor of 0% means
the gate reports this debt and does not yet fail on it — **that is a known gap, not
a pass**, and it is quoted here as a gap.

### A7. A negative names its universe

"No record was found" is admissible only as "no record was found **in {named
sources}, searched {date}, for {query}**". A universe-free negative is **CUT**, not
"clean".

*Bought by:* the ethics/participant zeros, where "no filing" meant "we did not
search the court that files them".

### A8. No silent cut

Text a reader will treat as complete may not be silently shortened. Every
truncation site is classified by what the code does with the value:

| class | meaning | admissible? |
| --- | --- | --- |
| `fixed_width` | format-constrained (hash, column, ID) | yes |
| `signature` | function signature / tool schema | yes |
| `labelled` | the elision is printed (`...`, `[truncated]`) | yes |
| `elision` | explicit shortening for a stated budget | yes |
| `display` | UI/table column | yes |
| `message` | log/error text | yes |
| `silent` | a value whose consumer cannot tell it was cut | **no** |

Two counts, never one: **sites** and **verdict-adjacent sites** (a site whose
truncated value feeds a pass/fail decision). A verdict-adjacent silent cut is a
**contamination of the verdict**, not a formatting preference.

*Measured 2026-11-05:* `tools/truncation_census.py --json logs/truncation.json`
→ `929 site(s) in 227 file(s) [silent=427 elision=8 labelled=40 fixed_width=48
display=337 message=53 signature=16]`, `verdict-adjacent: 60 site(s), of which
silent: 18`. The 18 are the review queue; the other 911 are classified, which is
the deliverable — a class, not a count.

The instrument was corrected **three times** before its number was quotable
(931 sites/424 verdict-adjacent → 933/77 → 933/18 → 929/18 after the tree moved).
An instrument's first reading is a hypothesis about the instrument.

### A9. A stale artifact answers for a tree it no longer describes

No generated count, census, probe or cache is evidence until its **age and its
subject** are stated. `state/head.json` older than `HEAD` is not state; a report
whose HEAD pin does not resolve is not a report.

*Measured 2026-11-05:* `tools/head_audit.py` found two orphaned worktree HEADs
(`.../Temp/kilo/baselinewt` `c7caa6061432`, `.../Temp/opencode/headwt`
`ed3f0e9f635e`) surviving only in reflog — a `git gc` takes them — plus one
prunable registration. A SHA that resolves only in a reflog is **not a pin**.

### A10. Reproduction, and what "stable" means

A finding is reproducible when the **grade** survives a re-draw. It is *not*
required that individual votes survive.

*Measured 2026-11-05, pin C4, two independent draws:*

| draw | tally | share | grade |
| --- | --- | --- | --- |
| r8 | 0 SUPPORTED / 2 PARTIAL / 3 UNSUPPORTED / 1 BLOCKED | 0.50 | NO_QUORUM |
| r8-c4-recheck | 0 / 3 / 2 / 1 | 0.50 | NO_QUORUM |

The grade reproduced; **five of six individual judges moved**. Quoting the vote
tally as the finding would have been quoting noise; quoting `NO_QUORUM 0.50` is
quoting the reading.

## PART II — CORROBORATION

### B1. Six angles from one model are one source

**Independence must be stated before agreement is counted.** Six personas served by
one model are *angle diversity*, not model diversity, and the artifacts say so in
`meta.independence`.

### B2. Unanimity at identical confidence is a prior, not corroboration

Before quoting unanimity, measure **degrees of freedom**: distinct verdicts and the
confidence spread.

*Measured 2026-11-05, round r8, 42 calls, 0 blind:*

| pin | votes | confidence min/med/max | distinct quotes |
| --- | --- | --- | --- |
| C1 | 6/6 PARTIAL | 0.65 / 0.65 / 0.65 | 3 |
| C2 | 6/6 PARTIAL | 0.65 / 0.65 / 0.65 | 1 |
| C3 | 6/6 PARTIAL | 0.60 / 0.65 / 0.65 | 1 |
| C5 | 6/6 PARTIAL | 0.65 / 0.65 / 0.65 | 2 |
| C6 | 6/6 PARTIAL | 0.65 / 0.65 / 0.65 | 1 |
| C7 | 6/6 PARTIAL | 0.65 / 0.75 / 0.75 | 2 |
| C4 | split | 0.00 / 0.15 / 0.60 | 1 |

Five pins returned **six identical verdicts at the identical confidence 0.65**.
That is one distribution, sampled six times — admissible as "the rubrics do not
disagree", **not** as "six judges found support". The confidence field is
**uncalibrated** and may not be used as a measure of support. C4 is the only pin
where the spread opened, and it is the only pin whose excerpt does not answer its
claim.

### B3. No quorum is not a weak verdict

A pin whose top share is below `arena.quorum` (0.66) is **`NO_QUORUM`**. It is not
`PARTIAL`, not `SUPPORTED`, and not a grade at all.

*Bought by:* a coercion defect fixed 2026-11-05. `grade_pin` reported
`PARTIAL if tally["PARTIAL"] or tally["SUPPORTED"] else "UNSUPPORTED"` with the
reason "no quorum: …", so a 0.50 split printed as **`PARTIAL` with the word "no
quorum" beside it**. A reader takes the grade and drops the reason. Corrected to
`NO_QUORUM` with the share in the reason, exit 1 (`no verdict obtained for: C4`),
and re-derivable from recorded rows via `--regrade` rather than 42 fresh calls.

### B4. BLIND is not zero, and zero is not BLIND

Four states, never collapsed: **`ok`**, **`empty`**, **`skipped`**, **`error`**.
A provider that was blocked reports `blocked`, not "0 results". A judge that could
not answer is `BLIND` and is **excluded from the tally**, never counted as dissent.

*Bought by:* the deep-dive web leg calling DuckDuckGo's 14 KB challenge page
`ok, 0 results` while it contained zero result anchors.

### B5. A quote converges on the exhibit, not on the corpus

When six angles return the same sentence, the finder has learned that the judges
may only cite **the supplied excerpt** — the arena sees a bounded quote per pin
(`arena.quote_chars`), not the source. Quote convergence is therefore evidence
about the packet's construction, and must not be reported as six independent
selections of the same passage.

## PART III — INSTRUMENTS

### C1. Classify, do not count

A sweep that returns a number invites the question "is that a lot?"; a sweep that
returns **classes** answers it. Every census output carries class buckets, and
every class states whether it is admissible (A8 table).

### C2. An instrument is a suspect until it has been made to fail

Before an instrument's reading may be cited, show a case where it reports the bad
thing. A negative control whose fixture **you wrote** validates your assumptions,
not reality — transcribe from the producer's source or capture from a real run.

### C3. A narrow run must not answer for a wide one

Separate artifact per scope (`--staged`, `--file`, `--pins`). Only the widest run
owns the widest report file.

### C4. Regrade from rows; re-run only for new evidence

When the *rule* changes and the *evidence* did not, re-derive from the recorded
rows (`--regrade`). When the evidence is in doubt, re-draw. Confusing the two
either manufactures evidence or wastes a run; the C4 draws in A10 are the model of
doing both, separately, and reporting both.

### C5. Fix the instrument, not the finding

A finding produced by a broken instrument is not fixed by re-baselining, suppressing
or ignoring it. Three census corrections on 2026-11-05 changed the count by 23×
(424 → 18 verdict-adjacent); the tree did not change once.

## PART IV — SETTINGS AND ENVIRONMENT

### D1. One surface, four layers

`config/defaults.json` → `config/defaults.<env>.json` (env from `AZAZAEL_ENV`) →
`AZAZAEL_DEFAULT_<DOTTED_KEY>` → the shipped constant in `defaults_profile.DEFAULTS`
as fallback. `read_default()` is the only reader; a knob that lives in three tools
drifts in three tools.

### D2. No orphan knobs, and no shadow readers

A leaf that nothing reads is dead settings; a reader no config declares is a
bypass. Both are findings.

*Measured 2026-11-05:* `tools/settings_shadow.py` →
`30 config leaf(s), 30 key(s) read across 481 module(s), 30 shared, 0 finding(s)
[none]`, reader vocabulary `get_default, read_default, setting` (from
`config/defaults.json`). Pre-session the same instrument read
`19 leaf(s), 13 read, 7 finding(s) [bypass_reader=1, orphan_knob=6]`.

### D3. A disabled gate says so, and is not a pass

A gate switched off by config exits **2** with the reason printed. `false` is not
`0`.

*Measured 2026-11-05:* `AZAZAEL_DEFAULT_GOLDEN_ARROW_ENABLED=false` →
`GOLDEN ARROW: disabled by golden_arrow.enabled=false … EXIT=2`.

### D4. Extend the default; never shadow it

A new check joins an existing gate as a bounded, isolated, recorded leg with its own
state (`ok|empty|skipped|error`) — not a private timeout, not a private exit code.

## PART V — THE VERDICT LADDER

| verdict | means | may be used to |
| --- | --- | --- |
| **VERIFIED** | tier-A source + grounding + identity keys | assert a fact |
| **CORROBORATED** | A/B plus C, or unanimous independent sources with measured degrees of freedom | assert a fact, naming the corroboration |
| **PARTIAL** | some support, quorum reached, scope stated | assert that support exists *within the stated scope* |
| **NO_QUORUM** | the finders split below quorum | report a split; **never** a verdict |
| **BLIND** | the instrument could not answer | report an outage; never zero |
| **LEAD** | identity-only, snippet-only, unverifiable, tier-D | queue for the next sweep |
| **CUT** | hostile to admissibility (universe-free negative, silent verdict-adjacent cut, ungrounded quote) | nothing. Fix the finding or drop it |

A verdict ladder with a rung that can be skipped is a ladder with a hole; the rungs
are exclusive and every finding sits on exactly one.
