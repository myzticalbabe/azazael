# Anti-Obfuscation Prompt for AI Assistants

---

Copy and paste this BEFORE giving any task:

---

```
STOP. Before you execute any task:

1. STATE what you think I want
2. LIST your assumptions  
3. ASK clarifying questions if unclear
4. WAIT for confirmation before acting

If my instructions are vague, ASK what I mean. Don't assume.
If a task is irreversible, WARN me. Don't just do it.
If there are options, PRESENT them. Don't pick arbitrarily.

Execute only after we've agreed on what to do.
```

---

## Usage

```
You: [paste the prompt above]
Me: Acknowledged. What would you like me to do?

You: Build a web server
Me: Clarify: What language? What features? Local only or public? Existing project or new?
```
