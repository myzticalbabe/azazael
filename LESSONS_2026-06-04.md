## #54 G: Drive Archive Reorganization — Sync Strategy for Slow SD Card Media

**Discovered:** June 4, 2026 — during G: drive reorganization session

**Root cause:** The G: drive is a 477 GB SD card (22% used). Bulk file operations (cp -r, rsync) take 600+ seconds and timeout. The previous sync strategy of copying everything was impractical.

**The fix — targeted sync strategy:**
1. Use `diff` to compare file trees (not cp)
2. Target only newer/changed documentation, configs, and templates
3. Skip build artifacts (.mypy_cache, .pytest_cache, .venv-3.14t, __pycache__)
4. Use `cp -u` (update mode — only copy when source is newer)
5. Archive legacy files to archive/ subdirectories (don't delete)

**What was moved to archive:**
- PHASE_6_TODO.md, PRODUCTION_TODO.md, REWRITE_TODO.md → archive/legacy_todos_20260604/
- build_all.py → archive/build_scripts/ (canonical at Desktop/AZAZAEL_Standalone/)

**What was synced (23 files + 3 directories):**
- All root documentation files, skills/, dashboard/, templates/
- Full sync to source-of-truth/azazael/ (40 files)
- Subdirectories src/ and tests/ NOT fully synced (timed out — noted as potentially stale)

**Created:** G:/AZAZAEL/ARCHIVE_STRUCTURE.md, G:/source-of-truth/README.md

**Prevention:** Use targeted copies, run diff before sync, document stale directories.

## #56 CODEX/CORE Worm Wrappers — @register_worm Pattern for Standalone Tools

**Discovered:** June 4, 2026 — during worm integration followup

**Root cause:** 4 standalone CODEX/CORE tools lacked @register_worm decorators and couldn't be discovered by the worm pipeline.

**Created:** CORE/WORMS/CODEX_TOOLS.py with 4 wrapper classes:

| Worm | Category | Priority | Cooldown | Tool Wrapped |
|------|----------|----------|----------|-------------|
| CainAnalyzerWorm | analysis | 5 | 120s | CAIN_ANALYZER |
| AutoDownloaderWorm | orchestration | 4 | 300s | AUTO_DOWNLOADER |
| EmojiMakerWorm | visualization | 3 | 60s | emoji_maker |
| EnhancedAnimationsWorm | visualization | 3 | 60s | enhanced_animations |

**Key pattern discovery:** @register_worm does NOT accept version= parameter. Version is extracted from cls.VERSION class attribute. All 4 worms have VERSION = "1.0.0".

**Prevention:** Add worm wrappers for all standalone tools in CORE/WORMS/.
