# Azazael Secrets Manager

## Overview
`CORE/secrets_manager.py` — Single source of truth for ALL API keys across the Azazael project. Consolidates .env files, config JSONs, and environment variables into one auditable store.

## Quick Start
```python
from CORE.secrets_manager import SecretsManager, audit_secrets, get_secret

sm = SecretsManager()

# Get a key
key = get_secret("MISTRAL_API_KEY")  # or sm.get("mistral")

# Audit all providers
for r in audit_secrets():
    print(f"{r['provider']}: {r['status']}")

# Status summary
configured, total = sm.status_summary()  # e.g., (7, 12)

# Add key to .env
sm.add_to_env("COHERE_API_KEY", "your-key", "Cohere trial key")
```

## Load Order (Priority)
1. **Environment variables** (highest priority — `os.environ`)
2. **~/.env file** (project-level config)
3. **~/.azazael/{provider}_config.json** (fallback, auto-generated by providers module)

## API Reference
| Method | Purpose |
|--------|---------|
| `SecretsManager()` | Singleton instance |
| `.get(key)` | Get secret by env var name or provider ID |
| `.has(key)` | Check if secret exists (non-empty) |
| `.audit()` | Full audit of all providers with status |
| `.status_summary()` | Returns (configured_count, total_count) |
| `.add_to_env(env_var, value, comment)` | Add/update key in ~/.env |
| `.reload()` | Force reload from all sources |
