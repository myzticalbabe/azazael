• go run / go build, module-aware (go.mod), gofmt, cross-compile

OpenMono Integration

The INTERPRETERS package mirrors the openmono-rebuild pattern: each language gets a dedicated runner class with compile, run, test, and lint capabilities. The unified registry in __init__.py provides a single InterpreterRouter that dispatches code to the correct language runner.
