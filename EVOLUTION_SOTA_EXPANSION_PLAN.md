## 2. SOTA gaps — verified absent, not assumed

A keyword sweep over `src/CORE/WORMS/expansion/` returns **zero files** for every
term in this table. These are not "underexploited"; they do not exist.

| Missing capability | Why it matters | Symptom it already causes |
|---|---|---|
| **Multi-fidelity scheduling** (Hyperband / ASHA / BOHB) | evaluate many candidates cheaply, promote few | every genome costs full fidelity; `pareto_refine` alone is 93.4% of wall clock |
| **Hierarchical Bayesian evidence** (era as random effect) | evidence must survive a changing pool | **E4**: 28 pool eras, streak/SPRT reset at every change |
| **Uncertainty-aware promotion** (posterior, not fixed threshold) | a fixed gate on a drifting baseline is meaningless | **E5**: margins chased a baseline that drifted 5.94 |
| **Surrogate with uncertainty** (GP / deep ensemble) | decide what to evaluate next | TPE gives a point estimate only; no acquisition function |
| **High-dimensional QD** (CVT-MAP-Elites, AURORA) | diversity at useful resolution | **Cortex**: 16 cells, coverage 0.75, archive saturates |
| **Novelty / curiosity pressure** | escape elite freeze | **E3**: 42/50 flat trajectories after widening |
| **Allocative operator selection** (bandits / Thompson) | fund operators by measured value | **E10**: arm skipped **50/50** by a fixed `2x` threshold |
| **LLM-guided variation** (FunSearch / AlphaEvolve style) | mutate with structure, not noise | random SBX only; no use of the 16 installed providers |
| **Self-adaptive search policy** | search that tunes its own search | meta-params are a separate, slower loop |
| **Adversarial / living curriculum** | a static pool gets overfit | **E9**: +3.3 snapshot margin bought **0/4** holdout passes |
| **Continual / cross-era transfer** | don't relearn per era | **E4** again |
| **Many-objective** (>2) | real problems have >2 axes | NSGA-II is 2-objective |
| **Verifier / learned reward** | gate on capability, not a scalar sum | promotion rests on one summed number |
| **Self-play / co-evolution** | no adversarial pressure at all | the baseline never fights back |

**The through-line:** the system optimises a *scalar on a frozen pool* and is
judged by *fixed thresholds across a moving world*. That is the root of E3, E4,
E5 and E9 together. Adding more operators would not fix a structural problem.

## 3. The proposal: ANIMA

**ANIMA — Autonomic Nested Inference & Metabolic Allocation.**

Not a new optimiser bolted on, but a change of framing: the search becomes a
*physiology* with metabolism, memory, senses and an immune system, all CPU-
feasible and all built from numpy/scipy plus what is already in the tree. The
claims below are deliberately falsifiable (section 6).

### 3.1 Cranium — memory that survives eras *(fixes E4, E5)*
Replace the era-pinned SPRT with a **hierarchical Bayesian posterior** over the
true effect size. Each pool era is a random effect; evidence is pooled through a
shared global mean instead of being discarded at every era boundary.

- Conjugate **normal-inverse-gamma** updates, closed form, no sampling.
- Promotion requires `P(effect > threshold | all eras) >= 1 - alpha`, which
  handles a drifting baseline *by construction* rather than by a fixed margin.
- Cost: microseconds. Replaces `_sprt_decide` + `_sprt_history` in-place.
- New: `expansion/evidence.py`.

### 3.2 Crucible — an adversarial living curriculum *(fixes E9)*
The evaluation pool stops being a frozen snapshot.

- A **Pool Curator** maintains a difficulty-weighted sampler that is *re-derived
  each cycle* to maximise the current champion's loss (hard-example mining).
- A **KEEPER set** is never shown to the search. Fitness is reported on the
  Curator pool; **promotion is judged only on the Keeper**.
- `dreaming.py` is already able to emit synthetic eval rows, so the Curator can
  *synthesise* hard cases, not just re-weight existing ones — the pool can grow
  against the champion.
- This is the direct, measured cure for E9's 0/4: a static pool cannot overfit
  if it moves against you, and the Keeper is an unbiased referee.

### 3.3 Circulation — metabolism *(fixes E10)*
Compute becomes a budget allocated by **Thompson sampling over operators**
`{GA, CMA-ES, DE, Chorus, Novelty}`.

- Each operator keeps a Beta/Bernoulli posterior on "produced the promoted
  genome"; allocation follows posterior draws.
- The fixed `margin < 2 * PROMOTE_MARGIN` arm gate disappears — an operator that
  starts winning earns budget, and one that never does fades.
- This is the structural fix for a 50/50 starved arm: no threshold to fall off.

### 3.4 Chorus — voice *(new capability)*
A **FunSearch-style LLM variation operator** using the installed
`CORE/inference/providers.py` (16 providers, already networked and cached via
`inference_cache.py`). It conditions on the recent *failure modes* — the holdout
failure logs and the pinned-gene report — and proposes structured edits
(widen this bound, add this gene, change this schedule) rather than noise.

- CPU-feasible because it is API-side; `transformers` is not needed.
- Budget-capped and cached, so it cannot dominate wall clock.

### 3.5 Cortex — development *(upgrades QD)*
Replace the 4x4 grid with **CVT-MAP-Elites**: k-means centroids (numpy, no
sklearn) over descriptors that are *learned* rather than hand-picked, plus
**QD-score** for archive comparison. Descriptors start as `(info, alert)` and
extend to era-normalised margin, gene dispersion, and pool hardness.

### 3.6 Immune — defence *(new)*
**Regression quarantine.** A genome that wins on the Curator but loses on the
Keeper is quarantined, not promoted, and its gene signature is recorded so the
Curator can generate neighbours of it. Anomaly detection on the Keeper margin
distribution auto-rolls-back a promotion that degrades within N cycles.

### 3.7 Metabolism — multi-fidelity *(new, biggest wall-clock win)*
**Successive halving** over evaluation fidelity: score candidates on a 1-salt,
reduced-episode proxy, keep the top 1/eta quartile, spend full 3-salt fidelity
only on survivors. Phase 0 measures whether the proxy actually ranks
(spearman rho) before this is trusted — a multi-fidelity scheduler on an
uninformative proxy is worse than none.

### 3.8 Isles — geography
Extend `IslandModel` to **Population-Based Training**: islands exploit (copy
weights/hyperparameters from better islands) and explore (perturb), so search
policy transfers instead of being rediscovered per island.

## 4. Phased plan

| Phase | Deliverable | Fixes | Risk |
|---|---|---|---|
| **0. Measure** | stage-cost instrumentation; proxy-vs-full-fidelity rank correlation | — | none, pure measurement |
| **1. Memory + metabolism** | Cranium (Bayesian evidence), Circulation (Thompson bandit), Successive halving | E4, E5, E10, wall clock | low |
| **2. Adversary + diversity** | Crucible (Curator + Keeper), Cortex (CVT-MAP-Elites, QD-score) | E3, E9 | medium — changes the fitness contract |
| **3. Voice** | Chorus LLM operator behind a budget cap | creativity | low (fail-open) |
| **4. Architecture** | Immune quarantine, Isles/PBT, NSGA-III many-objective | robustness, >2 objectives | medium |

Phase 1 is where the evidence is strongest and the risk lowest; it needs no new
dependencies. Phase 2 changes what "fitness" means, so it must land *after*
Phase 1 has been measured, and it should be evaluated on holdout pass rate — not
on margin, which we now know is not evidence (E9).

## 5. What "enlivened" concretely means here

The system gains, in code, the properties that made the failures legible:

- **Drives** — a homeostatic diversity setpoint; novelty pressure engages when
  Cortex coverage stops rising.
- **Metabolism** — an explicit compute budget consumed by operators that earn it.
- **Senses** — a pool that is *grown against* the champion rather than frozen.
- **Memory** — evidence that compounds across eras instead of resetting.
- **Immunity** — regressions are quarantined and reverted automatically.
- **Voice** — the search can propose structure, not just sample noise.
- **Aging** — eras still succeed one another, but the Cranium remembers them.

That set is what makes it a living substrate rather than a loop: each era leaves
the system *measurably different* instead of resetting it.

Measured against the 2026-09-11 widened-bounds batch:

|---|---|---|---|
| 1 | Holdout pass rate | **0/4 (0%)** | > 25% of held-out attempts |
| 2 | Evidence spans eras | 1 era (resets) | posterior reported across >= 3 eras |

| 5 | Proxy rank correlation | unmeasured | spearman rho >= 0.6 vs full fidelity |
| 6 | Cortex archive | 16 cells, cov 0.75 | >= 100 cells, QD-score rising |

Criterion 1 is the only one that matters on its own: everything else is
instrumental. The widening proved the search can move; now the goal is for
movement to *transfer*.

## 7. Risks and constraints

- **CPU-only, 16 GB.** No local LLM, no GPU training. Cranium/Curator/CVT and
  the bandit are all numpy/scipy — chosen precisely because of this.
- **No scikit-learn.** k-means and any GP must be hand-rolled in numpy or the
  dependency added deliberately.
- **Chorus cost.** API latency and rate limits; must be budget-capped, cached
  (`inference_cache.py`), and fail-open.
- **Fitness contract change.** Phase 2 alters what fitness means; it must not be
  mixed into a batch used to validate Phase 1, or the comparison is confounded.
- **Do not repeat E9.** Any new gate must be evaluated on the Keeper, never on
  the pool the search optimises.

## 8. First concrete step (recommended)

Phase 0 only: instrument stage costs and run the proxy-vs-full-fidelity
correlation study on the already-collected 50-run logs. It is pure measurement,
needs no new dependencies, and it decides whether multi-fidelity (section 3.7) is
worth building at all. Everything else in this plan is contingent on it.
