### abstract

```
SHARDEX mirrors a codebase, shatters it into content-addressed shards, and forges a shard into a FLAME game engine arena. The pipeline runs on Python stdlib (mirror, shatter) with Node+puppeteer+Chrome for the browser forge step. Outputs a deterministic golden-state hash for verification.
```
