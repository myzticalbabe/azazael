The failure

A sentence that reads verified
and checks nothing.

A path

"I updated the config at
src/core/settings.py"

The file does not exist. Nothing in the loop stats it.

A command

"tests pass"

No command was run, or a different one was, or it failed and the summary did not.

An outcome

"the issue is fixed"

The edit landed; the behaviour was never observed. Those are two different claims.

Bigger models lower the rate. They do not make the claim checkable.

PROJECT CRADLE3 / 7
Why it is infrastructure

Local, vendor-neutral,
and it cannot become the risk it audits.

  • Never holds weights, never needs an API key
  • Speaks the OpenAI chat shape — Ollama, llama.cpp, LM Studio, vLLM
  • Standard library only, so the verifier adds no supply chain
  • Same check against whatever model you install next

The three commands

cradle.py --doctor
cradle.py --demo
cradle.py --serve --model-url …

--demo includes a deliberate failed verification, so a lesson is seen to be written and then recalled.

A commons artefact: the vocabulary and the lesson format published as a spec others can implement.

PROJECT CRADLE4 / 7
Where it actually stands

Both halves, or neither is true.

Exists and is measurable

  • Four parts, composition, three commands, five endpoints
  • Eight chain tests that skip when a sibling is absent — never weakened
  • Reference platform documented: Core Ultra 9 285H, Arc 140T 8 GB, 32 GB

Does not exist yet

  • No independent security review — the refusal path has never been read by anyone else
  • One maintainer; docs assume the author's machine
  • Windows-first; Linux and macOS untested
  • No measured catch rate — so no efficacy claim is made

The last line is the reason for this application.

PROJECT CRADLE5 / 7
What the grant buys

Six deliverables, each written
so that it can fail.

D1 · Corpus

300 labelled agent claims, 150 resolving / 150 not, provenance per claim.

D2 · Catch rate

Confusion matrix with a lower bound. A poor number is published as it stands.

D3 · Portability

Linux and macOS pass --doctor and --demo; interpreter matrix per platform.

D4 · Review

Independent reviewer, findings published in full — including the unfixed ones.

D5 · Spec

Vocabulary, frame lifecycle, refusal reasons, lesson format. A third party implements from it.

D6 · First run

A stranger reaches a refusal and can say why, without reading the source.
