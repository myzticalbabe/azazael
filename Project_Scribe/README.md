# Scribe

**Documentation generation tooling extracted from AZAZAEL.** Automated docs from code, Mermaid diagrams, API reference generation.

## Overview

Scribe provides automated documentation generation for Python projects:
- Automatic docstring extraction
- Mermaid diagram generation from code structure
- API reference generation
- Cross-reference linking

## Installation

```bash
pip install -e .
```

## Usage

```bash
python -m scribe --help
```
