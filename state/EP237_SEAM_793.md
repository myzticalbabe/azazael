### Smallest honest change (recommendation only — NOT implemented)

Owner file: **`src/CORE/workflow.py`**.

1. Give `WorkflowEngine` an opt-in `MapBeforeAct` stage — constructed from a root
   the engine already knows, with `record_to` pointed at the run's evidence path,
   and `None` by default so the engine's current behaviour is unchanged. This
   matches the stage's own opt-in contract (`graph_artifacts.py:133-144`).
2. Call `stage.consult(target)` at the head of `_execute_step`
   (`src/CORE/workflow.py:675`), before the `action` dispatch — that is the only
   place where every action passes through exactly once.
3. **Blocking detail, stated rather than glossed**: `WorkflowStep`
   (`src/CORE/workflow.py:111-124`) has **no** `target` field. Its fields are
   `id`, `action`, `params`, `depends_on`, `condition`, `timeout`, `status`,
   `result`, `error`, `started_at`, `completed_at`, `duration_ms`. So "which
   target is this step about to act on" is not expressible today. The honest
   wiring therefore needs either (a) a new optional `target: str = ""` field on
   `WorkflowStep` set from the DSL, consulted only when non-empty, or (b) a
   documented convention mapping specific `params` keys to the consultation
   target. Option (a) is additive and keeps "no target, no consultation"
   explicit; either way the step's target is a *new* piece of information, not
   something already available to infer.
4. Do not back `MapBeforeAct` onto `InferenceLoadBalancerWorm`. The brief's
   MetaCluster→servemesh path cannot carry a code-map consultation; wiring it
   there would produce a second inert caller, which is the failure mode
   `NEURAL_MESH_ARCHITECTURE_AUDIT_2026-09-15.md:384` describes.

### Acceptance test for the seam (for whoever implements it)

A step with a non-empty `target` records one consultation whose `node_id`
matches the target, and a step with no target records none — asserted against a
`tmp_path` graph, so the test does not depend on the live tree (the pattern
`tests/test_map_before_act.py` already uses at `:120-139`).
