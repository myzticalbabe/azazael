# Project PERSEPHONE Sync

**Cross-platform environment synchronization — the PERSEPHONE component of the Azazael tree.**

## Overview

PERSEPHONE handles bidirectional synchronization of code, configs, and environments across Windows, WSL2 Ubuntu, bare metal Linux, and Kali. It manages the sync topology and integrity verification.

## Components

| Component | Role |
|-----------|------|
| `persephone/sync/` | Core sync engine, conflict resolution, topology |
| `persephone/verify/` | Integrity checks, hash verification, drift detection |
| `persephone/env/` | Environment status, dependency reconciliation |
| `persephone/bridge/` | E: drive bridge, network transport |

## Quickstart

```bash
python -m pytest tests/ -q
python -m persephone.sync --status
```
